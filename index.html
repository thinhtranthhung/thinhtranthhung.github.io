03. Some Things I've Built

Featured Project — System Architecture

Real-Time Traffic Analytics System

Architected and deployed a high-throughput, real-time data streaming pipeline capable of processing live CCTV video feeds from complex, high-density urban intersections (e.g., Hang Xanh, Lang Cha Ca).

Integrated YOLOv8 for continuous object detection and vehicle classification. Strictly optimized the model's inference speed to handle low-latency video streams without frame dropping. Synchronized this visual telemetry with real-time geospatial routing metrics via the TomTom API to provide deep context on traffic flow and congestion.

Securely persisted the processed data into Neon DB (Serverless PostgreSQL) for scalable storage and historical analysis. This project highlights a strong ability to build robust distributed architectures, integrate secure APIs, and manage heavy, continuous data loads.

  • Python
  • YOLOv8
  • Neon DB
  • TomTom API
  • Data Pipeline

Academic Project

A Mini Trading Platform

Engineered the core backend for a financial trading platform managing diverse instruments. Architected a highly modular system utilizing advanced Object-Oriented patterns: implemented the Observer pattern for real-time event broadcasting, the Strategy pattern for dynamic pricing, and the Visitor pattern for tax analytics.

Designing this complex architecture provided a deep understanding of application states, object lifecycles, and portfolio state management. This serves as a crucial foundation for identifying business logic flaws and architectural vulnerabilities during penetration testing.

  • Java
  • Design Patterns (GoF)
